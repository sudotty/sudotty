# sudotty

Full-stack / backend engineer building **production-grade AI agent systems**, browser automation products, and reliability-first AI workflows.

My current work is centered on one practical question:

> How do we make AI agents reliable enough for real work?

I care less about impressive chatbot demos and more about systems that can survive contact with users, data, tools, policies, failures, and review.

## Working Principles

- Build the smallest useful system first.
- Prefer boring reliability over decorative complexity.
- Make the invisible visible: traces, failures, costs, permissions, and decisions.
- Keep a human in the loop when actions are risky.
- Treat growth, automation, and agent execution as measurable feedback loops.
- Write clear docs because remote work is mostly asynchronous trust.
