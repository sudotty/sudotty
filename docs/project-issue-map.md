# Project Issue Map

This file maps the portfolio ideas into a practical issue order. Each repository should keep issues in this priority structure.

## Priority language

- `P0 / MVP`: must be completed before the project is useful for interview or demo.
- `P1`: makes the project production-like and more credible.
- `P2`: improves communication, polish, and hiring conversion.
