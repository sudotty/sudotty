# Next Build Sequence

This is the recommended order after the planning documents are ready.

## 1. RAG Reliability Lab

Goal: create the first visible demo.

Build:

- document list
- chunk view
- search comparison
- answer with sources
- small metric table

Why first: it has the clearest demo path and the fastest hiring signal.

## 2. MCP Tool Safety Gateway

Goal: show controlled tool use.

Build:

- tool list
- request preview
- input check
- access result
- record view

Why second: it shows platform thinking and makes the portfolio less generic.

## 3. Agent Eval Debug Suite

Goal: show repeatable quality checks.

Build:

- case list
- two run results
- timeline
- summary note

Why third: it turns the portfolio from demo work into quality work.

## 4. Human-in-the-loop Workflow Agent

Goal: show business workflow judgment.

Build:

- request intake
- extracted fields
- rule checks
- review screen
- final record

Why fourth: it connects agent design with real operations.

## 5. Issue-to-PR Coding Agent

Goal: show developer workflow understanding.

Build:

- issue intake
- selected files
- plan
- result
- test output
- review summary

Why fifth: it is useful, but harder to make credible without a working path.

## 6. Production Agent Starter Kit

Goal: integrate the patterns into a reference runtime.

Build:

- run list
- run detail
- step timeline
- model output
- review step
- evaluation note

Why last: it becomes stronger after the other projects define concrete needs.
