# Project Showcase Index

This index defines the demo shape for each project.

## RAG Reliability Lab

Show documents, chunks, search comparison, answer sources, metrics, and saved cases.

Strong point: quality is visible.

## MCP Tool Safety Gateway

Show tool list, request preview, input check, access result, and record view.

Strong point: tool requests are visible and typed.

## Agent Eval Debug Suite

Show case list, two runs, result table, step timeline, and summary note.

Strong point: quality is checked with repeated cases.

## Human-in-the-loop Workflow Agent

Show request intake, extracted fields, rule checks, summary, review screen, and final record.

Strong point: the workflow is concrete and easy to inspect.

## Issue-to-PR Coding Agent

Show issue intake, selected files, plan, result, test output, and review summary.

Strong point: the result stays small and easy to review.

## Production Agent Starter Kit

Show run list, run detail, step timeline, model output, review point, and final result.

Strong point: the runtime has visible state.

## Rule for all projects

Each project should first show one clear user path and one memorable engineering idea.
