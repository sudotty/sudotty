# GitHub Profile Checklist

This checklist keeps the profile focused for overseas AI Agent roles.

## Pin these repositories

1. `production-agent-starter-kit`
2. `rag-reliability-lab`
3. `mcp-tool-safety-gateway`
4. `agent-eval-debug-suite`
5. `hitl-workflow-agent`
6. `issue-to-pr-coding-agent`

## Suggested bio

```text
Full-stack engineer building production-grade AI agents: RAG reliability, MCP tool safety, HITL workflows, evals, and agent observability.
```

## Suggested location

```text
Tokyo / Remote
```

or:

```text
Asia timezone · Open to remote roles
```

## First-screen signal

Good signal:

- Original project
- English README
- Architecture notes
- Evaluation notes
- Demo workflow
- Clear issue roadmap

Weak signal:

- Old forks
- Unexplained experiments
- Empty repositories without issues
- Chinese-only notes for overseas job applications

## Tone guideline

Use calm and practical language.

Avoid:

```text
Revolutionary AI agent platform
```

Prefer:

```text
A production-style AI agent project focused on traceable execution, safe tool use, and eval-driven iteration.
```

The style should feel technical, humble, and readable.

Rilke-inspired language can appear in the profile, but project READMEs should stay practical and clear.
